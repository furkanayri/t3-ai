**Heplin panel** project includes three different panels:

1. Company Panel
2. Accounts Panel
3. Admin Panel

## 1\. Company Panel

The Company Panel has multi-tenant route pattern. Each company has own paths. For example Hitatek tenant access panel.heplin.com/hitatek

#### Running in development

`npm run dev:company`

#### Building for production

`npm run build:company`

## 2\. Accounts Panel

Candidates manage own bio in the accounts panel.

#### Running in development

`npm run dev:accounts`

#### Building for production

`npm run build:accounts`

## 3\. Admin Panel

Admin users can manage their tenants and users.

#### Running in development

`npm run dev:admin`

#### Building for production

`npm run build:admin`
