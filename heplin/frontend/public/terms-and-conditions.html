Kullanım Şartları

1. Şartların Kabulü

Web sitemize erişerek, bu Kullanım Şartları'na bağlı kalmayı kabul etmiş sayılırsınız. Bu şartları kabul etmiyorsanız, lütfen web sitesini kullanmayın.

2. Gizlilik Politikası

Gizlilik politikamız, bilgilerinizin nasıl kullanıldığını detaylandırmaktadır. Gizlilik politikamız hakkında daha fazla bilgi için KVKK Aydınlatma Metni sayfamızı ziyaret edebilirsiniz.

3. Web Sitesinin Kullanımı

Web sitemizi kullanırken aşağıdaki kurallara uymanız gerekmektedir:

  • Web sitesini yasadışı amaçlarla kullanmayacağınızı kabul edersiniz.
  • Web sitesinde sağladığınız her türlü içerikten tam sorumluluğu kabul edersiniz.
  • Başkalarının haklarını ihlal edecek içerik paylaşmayacağınızı taahhüt edersiniz.
  • Web sitesinin güvenliğini veya işleyişini bozmaya yönelik girişimlerde bulunmayacağınızı kabul edersiniz.

4. Fikri Mülkiyet Hakları

Bu web sitesindeki tüm içerik, T3 Foundation'a aittir ve telif hakkı yasaları ile korunmaktadır. Web sitesindeki içerikleri, yazılı izin olmadan kopyalama, dağıtma veya kullanma hakkınız bulunmamaktadır.

5. Sorumluluk Sınırlaması

T3 Foundation, bu web sitesinin kullanımından kaynaklanan doğrudan veya dolaylı zararlardan sorumlu tutulamaz. Web sitesi "olduğu gibi" sağlanmakta olup, herhangi bir garanti verilmemektedir.

6. Değişiklikler

Bu kullanım şartlarını istediğimiz zaman değiştirme hakkını saklı tutarız. Önemli değişiklikler durumunda, kullanıcılarımızı bilgilendireceğiz. Değişikliklerden sonra web sitesini kullanmaya devam etmeniz, güncellenmiş şartları kabul ettiğiniz anlamına gelir.

7. Uygulanacak Hukuk

Bu kullanım şartları, Türkiye Cumhuriyeti yasalarına tabidir. Bu şartlardan kaynaklanan herhangi bir uyuşmazlık, Türkiye mahkemelerinde çözülecektir.

8. Hizmet Kesintileri

Web sitesinde bakım, güncelleme veya teknik sorunlar nedeniyle geçici kesintiler yaşanabilir. Bu durumlardan kaynaklanan sorunlardan sorumlu tutulamayız.

9. Hesap Güvenliği

Web sitesinde bir hesap oluşturduğunuzda, hesap bilgilerinizin gizliliğinden ve güvenliğinden siz sorumlusunuz. Hesabınızın güvenliğini sağlamak için gerekli önlemleri almanız gerekmektedir.

İletişim

Bu kullanım şartları hakkında sorularınız varsa, lütfen bizimle iletişime geçin. İletişim bilgileri için KVKK Aydınlatma Metni sayfamızı ziyaret edebilirsiniz.
